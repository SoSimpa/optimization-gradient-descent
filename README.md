# Optimization: Gradient Descent Methods

Implementation and comparison of gradient descent variants for linear regression.

## Overview
- Synthetic linear regression data
- Batch Gradient Descent
- Stochastic Gradient Descent (SGD)
- Mini-batch Gradient Descent
- Cost convergence visualization
- Fitted line comparison against true parameters

## Setup & Run
```bash
pip install -r requirements.txt
python gradient_descent.py
```

## Skills Demonstrated
- Core optimization algorithms from first principles
- Understanding of learning rate, epochs, and batch size effects
- Cost function monitoring and convergence
- Visualization of optimization behavior
- Practical implementation of methods used in machine learning

Directly relevant to Michigan State Computational Data Science coursework, especially **CMSE 382: Optimization Methods in Data Science** and related numerical methods topics.

Educational project.
